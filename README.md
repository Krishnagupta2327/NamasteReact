# CraveCart 🍔⚡

A modern food discovery and restaurant browsing web app built using React. CraveCart integrates real-time restaurant APIs, dynamic search suggestions, reusable UI components, and scalable frontend architecture inspired by production-grade food delivery platforms.

---

## 🚀 Features

- 🔍 Live restaurant search
- 🍽️ Dynamic restaurant cards
- ⚡ Real-time API integration
- 🧠 Data normalization layer for handling multiple APIs
- 🖼️ Dynamic CDN-based image rendering
- ⭐ Ratings, cuisines, timings & pricing display
- 🧩 Reusable React component architecture
- 🔄 React Router based navigation
- 📱 Responsive UI
- 🛡️ Defensive rendering using optional chaining

---
